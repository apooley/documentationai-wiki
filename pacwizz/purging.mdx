## Before you start

Prepare the tank before beverage transfer using [Purging Connections](/pacwizz/purging-connections). Check [Safety & Site Requirements](/pacwizz/safety), and allow enough gas and time for the full run.

<Callout kind="danger">

Purging releases large volumes of gas. Keep appropriate ventilation/extraction operating and the outside vent route clear. **Do not leave a tank purging overnight.** Expect sudden venting noise and use hearing protection nearby.

</Callout>

## 1. Select Tank Purge

On **Mode Selection**, use **Up / Down** to select **Tank Purge**, then press **Enter**.

## 2. Set the four values

On **Purge SetUp**, use **Up / Down** to change the selected value and **Enter** to confirm it.

| Display label | Meaning | Manual's default example |
| --- | --- | --- |
| **Purge to Psi** | Pressure where gas injection stops during each purge cycle | 15 psi |
| **Vent to Psi** | Pressure where venting stops during each cycle | 3 psi |
| **Finish Psi** | Pressure reached after the last cycle and monitored afterward for a pressure-hold check | 9.25 psi |
| **Number of Cycles** | How many times to repeat the purge-and-vent process | 5 |

These values are a starting example, **not a universal recipe**. Choose settings that meet your process requirements without exceeding the tank, fittings, and relief-valve limits.

![Purge SetUp screen showing Purge to Psi 15.00, Vent to Psi 3.00, Finish Psi 9.25, and Number of Cycles 5.](/images/pacwizz/purge-setup.webp)

*The settings are also listed in the table above, so you do not need to read the photo to configure a run.*

## 3. Review the Purge Summary

Before the run starts, **Purge Summary** shows the calculated oxygen percentage after successive purge steps and the calculated final O₂ value.

The manual describes **below 1% oxygen** as a typical target for fermented products. Confirm the target required by your own process.

<Callout kind="info">

The O₂ value is a **calculated gas-space estimate**, not a measured oxygen reading or a dissolved-oxygen result for the beverage. It depends on the dilution model and chosen settings. See [Understanding Purge Calculations](/pacwizz/purge-calculations).

</Callout>

![Purge Summary screen listing oxygen estimates for five purges, a calculated final O2 value of 0.99%, and Continue? YES.](/images/pacwizz/purge-summary.webp)

## 4. Confirm or revise

- Choose **YES** and press **Enter** to continue with the purge.
- Use **Up / Down** to choose **NO**, then press **Enter** to return to **Purge SetUp** and change the values.

Review the entire setup, gas supply, and exhaust route before confirming **YES**.

## 5. Supervise the run

The PacWizz repeats gas injection and venting for the selected number of cycles, then brings the tank to the selected finish pressure.

Watch for gas-supply warnings. Purge time depends heavily on regulator flow capacity; see [Purge Times & Gas Supply](/pacwizz/purge-times) if pressure drops or a warning appears.

The manual does not provide a dedicated cancel-button sequence. Confirm the stopping procedure for your unit with [BrewWizz support](/pacwizz/support-and-warranty) before you need it, and use your facility's emergency procedure if a hazard occurs.

## 6. Check the completed run

After purging, the display shows the pressure at completion, purge duration, current pressure, and total elapsed time. Use these values for a [Post-Purge Pressure Check](/pacwizz/pressure-check) before transfer.
