## Pressure limits

| Item | Specification |
| --- | --- |
| Maximum head pressure | **15 psi** |
| Maximum foot pressure | **30 psi**, including the liquid's hydrostatic pressure |
| Tank protection | Appropriate tank pressure relief valve required; see [Safety & Site Requirements](/pacwizz/safety) |

<Callout kind="danger">

The 30 psi foot-pressure limit is **not** a tank-headspace operating rating. PacWizz is associated apparatus, not a pressure-rated tank, and does not replace the tank's relief valve.

</Callout>

## Measurement characteristics

The manual lists the following characteristics:

| Characteristic | Value |
| --- | --- |
| Head-pressure measurement range | 0–15 psi |
| Head-pressure resolution | 0.01 psi |
| Typical head-pressure accuracy | Better than 3% |
| Calculated repeatability | ±0.2 psi; the manual also lists 3% for this characteristic |
| Age-related error | Should not exceed 1.5%, according to the manual |

The source does not define the reference basis for these percentage figures. Ask BrewWizz for clarification if you need them for a measurement-quality or compliance decision. **Display resolution is not the same as accuracy.**

Pressure sensors are calibrated using a reference pressure gauge via a calibrated current meter. The manual describes the transducers as having low drift and long-term stability. Device calculations use **local atmospheric pressure and applied pressure**.

## Enclosure, mounting, and power

| Item | Specification |
| --- | --- |
| Enclosure | Modified NEMA 4 box |
| Approximate enclosure size | 10.5 × 7 × 4 in (26.7 × 17.8 × 10.2 cm) |
| Mounting | External brackets; can be wall-mounted or hung from the CIP arm |
| Power | **24 V DC, 24 W maximum** |
| Power supply | Manufacturer-supplied CAT II, double-insulated supply |
| Foot Pressure Sensor | 316 stainless steel, 1½-inch tri-clamp connection |
| Brite hose | 10 ft, 5/16-inch push-to-connect hose with stainless steel industrial fitting |
| RMB connection | 1½-inch tri-clamp fitting; supplied with purging versions only |

The manual labels the Brite hose's approval as **“NFS-61”**. Confirm the exact hose certification with BrewWizz if it is required for your installation; this guide does not assume that label means a different standard.

## Operating conditions

| Item | Specification |
| --- | --- |
| Use | Indoor |
| Maximum altitude | 2,000 m |
| Operating temperature | 5–40 °C (41–104 °F) |
| Maximum relative humidity | 80% up to 31 °C, decreasing linearly to 50% at 40 °C |
| Pollution degree | 2 |
| Maximum stated venting noise | 100 dBA |

## Certification statements in the manual

The manual states:

- NRTL (QPS) inspection for a portable product for the USA and Canada.
- North American **UL 61010** certification and **CE EMC** compliance.
- EMC compliance tested by a **UKAS laboratory**, covering the main assembly only.

If your site requires specific certification records or confirmation for your unit, request them from [BrewWizz support](/pacwizz/support-and-warranty).
