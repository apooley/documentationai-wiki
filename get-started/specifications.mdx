## Specifications

Technical data for the FizzWizz and the accessories covered in this documentation. Where a component has a full specification table on its own page, this page links to it rather than repeating it.

## FizzWizz Bubbles Anywhere Edition

### Dimensions

| Dimension | Imperial | Metric |
| --- | --- | --- |
| Width | 6 in | 15.2 cm |
| Height | 10.6 in | 26.9 cm |
| Depth | 5.7 in | 14.5 cm |

### Configuration

| Specification | Value |
| --- | --- |
| Mounting | Wall, tank, or other surface |
| Carbonation stones managed | Multiple, simultaneously |
| Connectivity | Wi-Fi |
| Control | Three front-panel buttons and a display |
| Operating modes | Carbonation, Pre-scrub, Head pressure, CO₂ flow control, Venting |

### Pneumatics

| Specification | Value |
| --- | --- |
| CO₂ supply pressure | 30–40 psi at the regulator |
| Solenoids | Three: CO₂_in, Head_Transfer, Vent |
| Circuits | CO₂ inlet, Stone (carbonation), Arm (head transfer) |
| Internal filter | Protects solenoids and transducers from particulate |

See the [Pneumatics Schematic](/get-started/pneumatics-schematic) for the full gas path.

### Construction

| Specification | Value |
| --- | --- |
| Internal tubing | FDA food-grade |
| Microbial control | Ultraviolet anti-microbial lamps on the stone lines |
| Electronics protection | Heat-cured conformal coating on circuit and sensor boards |

<Callout kind="alert">

The conformal coating reduces condensation risk but does **not** make the electronics waterproof. Keep liquid out of the enclosure and always use an arm separator.

</Callout>
