---
title: Cannot Upload Recipe
description: Fix recipe upload problems in Brew Wizz Docs.
---

## Symptoms
- Recipe upload fails
- Error: "File type not supported" or no response

## Causes
- Wrong file format
- File too large

## Solution
<Steps>
  <Step title="Check file format">
    Accepted: PDF, TXT, DOCX. Rename if needed.
  </Step>
  <Step title="Reduce file size">
    Recipes must be under 5MB. Compress large files.
  </Step>
  <Step title="Try again">
    Re-upload via "Add Recipe" on your dashboard.
  </Step>
</Steps>
