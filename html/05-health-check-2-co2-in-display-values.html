Check 2 confirms that the three sensor readings on the Test Mode display are accurate before any solenoid testing begins. If a sensor is misreading, every later check that depends on it becomes unreliable — so resolve failures here first.

Preconditions

  • Setup and Check 1 complete
  • CO2 connected to CO2_In, regulator set to 30–40 psi
  • Stone hose and arm hose still disconnected
  • FizzWizz in Test Mode

Reading A: regulator pressure

Compare the CO2 reg psi figure on the display against the dial on your supply regulator. They should agree within 3 psi, and the value should sit in the 30–40 psi band.

Record both numbers on the results form, not just the pass or fail — the gap between them is what tells you whether a transducer is drifting.

Reading B: Brite pressure

With the arm hose disconnected, the arm circuit is vented to atmosphere, so Brite psi should read essentially zero. Anything outside ±0.18 indicates a transducer problem, and often fluid in the pipe feeding the transducers.

Reading C: temperature

“Representative” means the reading should be plausible for wherever the probe currently is — roughly ambient if it is sitting in the open, or roughly tank temperature if it is still installed.

This is a sanity check, not a calibration. If you need to confirm the probe is genuinely accurate, run the Slushy WizzTemp Test, which verifies it against a known 0 °C reference.

If a check fails

IDSymptomAction
A Wrong reg psi Try a different CO2 regulator to rule out the regulator itself. If the reading is still wrong, change the CO2_In pressure transducer. Also check the CO2_In check valve.
B Brite psi reads wrong pressure Change the Brite pressure transducer, and inspect for fluid in the pipe leading to the transducers.
C Temperature reads wrong Change the WizzTemp sensor, and inspect the temperature sensor internal loom.
