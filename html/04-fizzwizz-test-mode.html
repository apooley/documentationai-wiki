Test Mode puts the FizzWizz™ into a diagnostic state where the display shows live sensor readings and the three front-panel buttons directly operate the internal solenoids.

You need Test Mode for the Health Check (Checks 2 to 6) and for the Slushy WizzTemp Test.

Entering Test Mode

  1. Start with the FizzWizz switched OFF.
  2. Press and hold the top two buttons (Up and Down). Keep them pressed.
  3. While still holding them, switch the FizzWizz on.
  4. Keep holding for 6 seconds. The unit will enter Test Mode.
  5. Release the buttons.

The display will read Test Mode at the top. If it boots normally instead, switch off and try again — the buttons must already be held down before power is applied.

The Test Mode display

Three live values are shown:

Display labelMeaning
CO2 reg psiPressure measured at the CO2 inlet. Should track your supply regulator.
Brite psiPressure measured on the arm / head transfer circuit.
TemperatureReading from the WizzTemp probe.

What the buttons do in Test Mode

Each button, when pressed and held, operates one internal solenoid:

ButtonSolenoidGas normally flows from
UpHead_TransferARM connection
DownCO2_inSTONE connection
EnterVentVent valve

Which port actually produces gas depends on where your CO2 supply is connected — that is the basis of Check 3 and Check 4.

Note on Check 7

Check 7 is the exception: it is performed in Carbonation mode, not Test Mode.

Leaving Test Mode

Switch the FizzWizz off and back on without holding any buttons. It will boot normally.
