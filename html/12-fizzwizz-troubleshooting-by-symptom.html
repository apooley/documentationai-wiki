Find the ID letter of the check that failed and work through its actions in order. The IDs match the Health Check procedure and the results form exactly.

Read this first. Faults affecting pressure transducers and solenoids are typically caused by fluid in the FizzWizz. This happens when the arm separator is either not used or is overwhelmed, or when check valves are stuck open or were never installed.

If several unrelated checks fail at once, find and fix the fluid path before replacing components — otherwise the replacements will fail the same way.

Power

IdentSymptomAction
Check 1 No green light, FizzWizz will not turn on Replace the plug-in power supply. Confirm the outlet is live and the connector is fully seated first.

Display values — CO2_In (Check 2)

IdentSymptomActions, in order
A Wrong reg psi
  1. Try a different CO2 regulator.
  2. Change the CO2_In pressure transducer.
B Brite psi reads wrong pressure Change the Brite pressure transducer, and inspect for fluid in the pipe leading to the transducers.
C Temperature reads wrong
  1. Change the WizzTemp sensor.
  2. Inspect the temperature sensor internal loom.
Confirm with the Slushy WizzTemp Test.

Solenoid function — CO2_In (Check 3)

IdentSymptomActions, in order
D Gas continuously flowing through stone connection Change the CO2_in solenoid — stuck OPEN.
E Gas continuously flowing through ARM connection Change the Head_Transfer solenoid — stuck OPEN.
F Gas continuously flowing through ARM and vent Change the Head_Transfer and Vent solenoids — both stuck OPEN.
G Flow meter ball is up Same cause as D. Change the CO2_in solenoid — stuck OPEN.
H Up button pressed, gas does not pulse through ARM Change the Head_Transfer solenoid — stuck CLOSED.
I Down button pressed, gas does not pulse through STONE
  1. The flow meter may be turned all the way off. Rotate the flow meter knob counterclockwise and retest.
  2. If it still does not pulse, change the CO2_in solenoid — stuck CLOSED.
J Enter button pressed, no clicking sound
  1. Check the vent valve is OPEN.
  2. Change the Vent solenoid — stuck CLOSED.

Solenoid function — ARM (Check 4)

IdentSymptomActions, in order
K Gas continuously flowing through stone connection Same as D. Change the CO2_in solenoid — stuck OPEN.
L Gas continuously flowing through CO2_in connection Replace the CO2_In check valve. The FizzWizz will still operate, but there is a risk of reverse fluid flow if the operation runs out of CO2.
M Gas continuously flowing through vent valve Change the Vent solenoid — stuck OPEN.
N Flow meter ball is up Same cause as D. Change the CO2_in solenoid — stuck OPEN.
O Up button pressed, no clicking sound
  1. Confirm the flow meter is not turned all the way off — rotate the knob counterclockwise and retest.
  2. If there is still no click, investigate the Head_Transfer solenoid.
P Down button pressed, gas does not pulse through STONE Same as I. Rotate the flow meter knob counterclockwise and retest; if still no pulse, change the CO2_in solenoid — stuck CLOSED.
Q Enter button pressed, gas does not pulse through vent valve
  1. Check the vent valve is OPEN.
  2. Change the Vent solenoid — stuck CLOSED.

Display values — ARM (Check 5)

IdentSymptomActions, in order
R Wrong reg psi
  1. Try a different CO2 regulator.
  2. Change the CO2_In pressure transducer.
  3. Replace the CO2_In check valve (see L).
S Brite psi reads wrong pressure Same as B. Change the Brite pressure transducer and inspect for fluid in the pipe leading to the transducers.
T Temperature reads wrong Same as C. Change the WizzTemp sensor and inspect the internal loom.

Leak tests (Check 6)

IdentSymptomActions, in order
U Pressure increased on finger test Replace the Head_Transfer solenoid — it has a small leak.
V Arm hose and separator pressure drops quickly
  1. Check the swiffer valve.
  2. Remove the separator and recheck.
  3. Suspect a leak in the arm hose or separator.
  4. Check the vent solenoid — see M, stuck OPEN.

Stone circuit (Check 7)

IdentSymptomActions, in order
W Ball stays down
  1. The flow meter may be turned all the way off. Rotate the knob counterclockwise and retest.
  2. Possible blocked carbonation stone.
  3. Check the sanitary and inline check valves.
X Ball stays up Check the stone hose for leaks, especially around the pneumatic push fittings.

Note on Ident O. The original troubleshooting guide cross-references Ident I here, which concerns the flow meter being turned off. Since check O is a listening test for solenoid actuation, the flow meter setting is unlikely to be the whole story — the Head_Transfer solenoid is the more probable cause if the click is genuinely absent. Both steps are listed above.
