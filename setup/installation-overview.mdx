## Installation overview

This section covers everything from planning a site through commissioning a working unit. The pages are ordered as a sequence: work through them in order for a new installation, or jump to the page you need for a change to an existing one.

<Callout kind="info">

**Before you start:** read [Site Requirements](/setup/site-requirements) first. Most installation problems trace back to something that was missing at the planning stage — insufficient CO₂ pressure, no tri-clamp port at the tank foot, or no arm separator.

</Callout>

## What is essential and what is optional

Not every site needs every component. The distinction matters when planning.

### Essential

| Component | Why |
| --- | --- |
| FizzWizz-BAE unit | The controller |
| Power supply | Included with the unit |
| CO₂ supply and regulator | 30–40 psi at the regulator |
| WizzTemp temperature sensor | The carbonation calculation depends on it |
| Stone hose and carbonation stone | Where CO₂ enters the tank |
| Arm hose **and separator** | The separator is the unit's main protection against fluid ingress |
| Tank PRV set to 15 psi | Safety requirement |

<Callout kind="danger">

Only use BrewWizz products with tanks that have a pressure relief valve (PRV) fitted. The PRV should be set to 15 psi.

</Callout>

### Optional

| Component | When you need it |
| --- | --- |
| [Foot Pressure Sensor](/setup/foot-pressure-sensor) | When packaging accuracy matters — eliminates hydrostatic pressure error. Requires FizzWizz-BAE V2 code or newer |
| [WizzKoga Selector](/setup/wizzkoga-selector) | Multi-tank sites wanting to switch sensors without moving them |
| [Battery Backup](/setup/battery-backup) | Sites with brownouts or short power cuts |
| [Ultrasonic Stone Cleaner](/setup/ultrasonic-cleaner) | Regular stone cleaning — strongly recommended for ceramic stones |
| Sensor switch box | Needed if you use a Foot Pressure Sensor on a FizzWizz, since both sensors share one port |

## After installation

Once the unit is commissioned and passing a Health Check, the ongoing tasks are:

- **[Monitoring](/get-started/monitoring)** the carbonation run from the dashboard
- **[Cleaning the carbonation stone](/setup/wizzstone-combo#cleaning)** after every use
- **[Servicing solenoids](/setup/solenoid-cleaning)** if product reaches them
- **Running a [Health Check](/troubleshooting/health-check/overview)** at the start of each season, after relocating the unit, or after replacing a component
