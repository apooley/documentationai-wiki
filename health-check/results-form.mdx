## Results form

Print this form and fill in actual measured values as you complete each check. Record numbers, not just pass or fail — the values help diagnose borderline or intermittent issues during support calls.

<Callout kind="tip" collapsed="false">
  Record the actual measured value, such as `13.277 psi` or `0.45°F`, in every column. Pass or fail alone is not enough. A completed form with real numbers is the single most useful thing you can provide when calling support.
</Callout>

## Check 6 — Leak testing (U–V)

<Callout kind="info" collapsed="false">
  Disconnect CO₂ from ARM and reconnect to CO₂\_In. Allow 2 minutes to settle before testing.
</Callout>

| Ident | Description                                  | Measured values                                       | Pass/Fail |
| ----- | -------------------------------------------- | ----------------------------------------------------- | --------- |
| U     | Gloved finger test — Brite pressure increase | Start: \_\_\_; Finish: \_\_\_; Finish − Start: \_\_\_ | \_\_\_    |
| V     | Arm hose + separator — Brite pressure drop   | Start: \_\_\_; Finish: \_\_\_; Start − Finish: \_\_\_ | \_\_\_    |

<Callout kind="alert" collapsed="false">
  The form records Start − Finish for Ident U, but the test detects a pressure **increase**. Record **Finish − Start** instead, so a positive value indicates the pressure rise the test is looking for.
</Callout>

## Check 7 — Stone hose and isolation valve (W–X)

<Callout kind="info" collapsed="false">
  Put FizzWizz in Carbonation mode before testing.
</Callout>

| Ident | Description                                 | Pass/Fail          |
| ----- | ------------------------------------------- | ------------------ |
| W     | Isolation valve OPEN — ball adjustable      | Pass / Fail \_\_\_ |
| X     | Isolation valve CLOSED — ball drops to zero | Pass / Fail \_\_\_ |

<Callout kind="alert" collapsed="false">
  The form says `~10 seconds` for the ball to drop, but the procedure says `~15 seconds`. Allow 15 seconds before recording a failure.
</Callout>
