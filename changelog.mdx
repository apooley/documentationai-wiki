## Recent Updates

Stay informed about the latest releases for the BrewWizz app and documentation. You receive new features, performance improvements, and bug fixes regularly. Check this page for details on each version.

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Added recipe sharing via QR codes for easy transfer between devices.
- Introduced fermentation tracking with temperature alerts.

## Improvements

- Enhanced user interface with dark mode support.
- Optimized app startup time by `>30%`.

## Bug Fixes

- Resolved sync issues with cloud backups.
- Fixed crash when importing large recipe files.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "improvement"]}>

## New Features

- Integrated ingredient scanner using device camera.
- Added customizable brewing timers with notifications.

## Improvements

- Improved recipe search with fuzzy matching.
- Reduced battery usage during background monitoring.

## Bug Fixes

- Corrected unit conversion errors for volume measurements.
- Fixed export to PDF functionality.

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Initial Release

- Core brewing recipe management.
- Basic inventory tracking for ingredients.
- Cloud sync for multi-device access.

## Breaking Changes

- Updated data format for recipes; migrate existing data via in-app tool.

</Update>

## How to Update the App

Follow these steps to ensure you run the latest version.

<Callout kind="info">
  Backup your recipes before updating to prevent data loss.
</Callout>

<Steps>
  <Step title="Check Availability" icon="smartphone">
    Open your app store and search for BrewWizz.
  </Step>
  <Step title="Download Update" icon="download">
    Tap Update if available.
  </Step>
  <Step title="Verify Version" icon="check-circle">
    Open the app and check Settings > About for the version number.
  </Step>
</Steps>

<Tabs>
  <Tab title="iOS" icon="apple">
    Visit the App Store and update via automatic settings or manually.
  </Tab>
  <Tab title="Android" icon="android">
    Use Google Play Store; enable auto-updates in Play Store settings.
  </Tab>
</Tabs>
